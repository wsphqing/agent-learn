# Docker 学习实验

先阅读上级目录的 [完整学习文档](../docker.md) 第 7～9 章。启动 Docker 服务后，按章节中的命令运行。

- `static-site/`：Nginx 静态页面，使用本机 `8081` 端口。
- `fullstack/`：Nginx + Python + PostgreSQL，使用本机 `8080` 端口。先按文档创建本地密码文件，再执行 Compose。
- `ai/`：Ollama 推理服务，使用本机 `11434` 端口。模型下载与服务启动是两个步骤。

这些都是本地学习案例。完整的前提、文件解释、预期结果、排错与清理步骤见主文档。当前生成环境未启动 Docker daemon，因此容器端到端实验未执行；验证范围记录在主文档末尾。
