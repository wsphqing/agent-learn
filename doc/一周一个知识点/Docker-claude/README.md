## 🎯 贯穿全文的实战项目

**一个典型的全栈应用**，我们会随章节一步步把它容器化并上线：

```
todo-app/
├── backend/     # Node (Express) 后端 API
├── frontend/    # 前端（Vite 构建的静态站点）
└── 数据库        # Postgres（存数据）+ Redis（缓存/会话）
```

| 章节 | 项目进展 |
|------|---------|
| 第 3 章 | 给 backend 写第一个 Dockerfile，构建成功 |
| 第 4 章 | 用多阶段构建打包 frontend，镜像瘦身 |
| 第 5 章 | 接入 Postgres，用数据卷保证数据不丢 |
| 第 6 章 | 打通 app ↔ redis 的容器间网络 |
| 第 7 章 | 用一个 Compose 文件一键拉起前端+后端+数据库 |
| 第 8~9 章 | 推送镜像并部署到云服务器，加 Nginx 反代 |
