# 附录 · Docker 速查表（Cheat Sheet）

> 日常敲命令随时来查。建议收藏 / 打印。

---

## A. 镜像相关

```bash
docker pull nginx:1.27-alpine        # 拉取镜像
docker images                        # 列出本地镜像
docker images -a                     # 含中间层镜像
docker rmi nginx:1.27-alpine         # 删除镜像
docker rmi $(docker images -q -f dangling=true)   # 删除所有悬空镜像
docker tag myapp:1.0 user/myapp:1.0  # 打标签（加一个名字）
docker push user/myapp:1.0           # 推送到仓库
docker history myapp:1.0             # 查看镜像的构建历史（各层大小）
docker inspect nginx:1.27-alpine     # 查看镜像详情（JSON）
docker save -o myapp.tar myapp:1.0   # 导出镜像为 tar 文件
docker load -i myapp.tar             # 从 tar 文件导入镜像
```

## B. 容器相关

```bash
# 创建并运行
docker run -d --name web -p 8080:80 nginx:1.27-alpine   # 后台运行 + 命名 + 端口映射
docker run -it --rm ubuntu:22.04 bash                   # 交互式进入，退出即删
docker run -d -e KEY=VALUE myimage                      # 传环境变量
docker run -d -v myvol:/data myimage                    # 挂载数据卷
docker run -d -v $(pwd):/app myimage                    # 绑定挂载
docker run -d --network mynet --name a myimage          # 指定网络
docker run -d --memory=512m --cpus=1.5 myimage          # 资源限制
docker run --rm -it --entrypoint sh myimage             # 覆盖入口，进 shell 调试

# 查看
docker ps                            # 运行中的容器
docker ps -a                         # 所有容器（含已停止）
docker ps -q                         # 只输出 ID
docker logs web                      # 看日志
docker logs -f --tail 100 web        # 跟随最后 100 行
docker inspect web                   # 详情 JSON
docker stats                         # 实时资源占用（CPU/内存）
docker top web                       # 容器内进程
docker port web                      # 查看端口映射

# 操作
docker exec -it web sh               # 进入运行中容器
docker stop web                      # 优雅停止
docker start web                     # 启动已停止的
docker restart web                   # 重启
docker kill web                      # 强制杀
docker rm web                        # 删除（需先停）
docker rm -f web                     # 强制删除
docker rm -f $(docker ps -aq)        # 删除所有容器
docker cp web:/app/log.txt ./        # 从容器拷文件到宿主机
docker cp ./file.txt web:/app/       # 从宿主机拷进容器
```

## C. 网络相关

```bash
docker network ls                                  # 列出网络
docker network create mynet                        # 创建自定义网络（支持容器名解析）
docker network inspect mynet                       # 查看网络详情（含容器 IP）
docker network connect mynet web                   # 把容器接入网络
docker network disconnect mynet web                # 断开
docker network rm mynet                            # 删除网络
docker network prune                               # 清理未使用的网络
# ⚠️ 自定义网络内，容器可直接用【容器名】当主机名互访
# ⚠️ 容器访问宿主机（macOS）：host.docker.internal
```

## D. 数据卷相关

```bash
docker volume ls                     # 列出卷
docker volume create myvol           # 创建卷
docker volume inspect myvol          # 查看卷详情（挂载点路径）
docker volume rm myvol               # 删除卷
docker volume prune                  # ⚠️ 删除所有未使用的卷（可能含数据！）
```

## E. 构建相关

```bash
docker build -t myapp:1.0 .                              # 构建（. 是构建上下文）
docker build -t myapp:1.0 -f Dockerfile.prod .           # 指定 Dockerfile
docker build --no-cache -t myapp:1.0 .                   # 不使用缓存，全新构建
docker build --build-arg VERSION=2.0 -t myapp:1.0 .      # 传构建参数（配合 ARG）
docker build --target builder -t myapp:builder .         # 只构建到某个阶段（多阶段调试）
docker buildx build --platform linux/amd64,linux/arm64 \
  -t user/myapp:1.0 --push .                             # ★ 多架构构建并推送
```

## F. Docker Compose 相关

```bash
docker compose up -d                 # 后台启动全套
docker compose up -d --build         # 先重新构建再启动（改了 Dockerfile 后必用）
docker compose down                  # 停止并删除容器+网络（保留卷）
docker compose down -v               # ⚠️ 连卷一起删
docker compose ps                    # 查看本项目的容器
docker compose logs -f backend       # 看某服务的日志
docker compose exec backend sh       # 进入某服务容器
docker compose run --rm backend npm test   # 跑一次性命令
docker compose restart backend       # 重启某服务
docker compose stop / start          # 停止 / 启动（不删除）
docker compose pull                  # 拉取所有服务的镜像
docker compose config                # 校验并打印最终的 compose 配置
```

## G. 清理与系统

```bash
docker system df                     # 查看磁盘占用概况（先看这个！）
docker system prune                  # 清理停止容器+悬空镜像+网络+构建缓存（较安全）
docker system prune -a --volumes     # ⚠️⚠️ 连未用镜像和【卷】一起清（有丢数据风险）
docker container prune               # 清理停止的容器
docker image prune                   # 清理悬空镜像
docker image prune -a                # ⚠️ 清理所有未被使用的镜像
docker volume prune                  # ⚠️ 清理未使用的卷
docker builder prune                 # 清理构建缓存
docker network prune                 # 清理未使用的网络
docker events                        # 实时事件流
docker info                          # Docker 引擎信息
docker version                       # 版本
docker login / logout                # 登录/登出仓库
```

## H. Dockerfile 指令速查

| 指令 | 作用 | 示例 |
|------|------|------|
| `FROM` | 基础镜像（第一条） | `FROM node:20-alpine` |
| `WORKDIR` | 设工作目录（相当于 cd） | `WORKDIR /app` |
| `COPY` | 拷文件进镜像 ★首选 | `COPY package*.json ./` |
| `ADD` | 拷文件（支持解压/URL，少用） | `ADD app.tar.gz /app/` |
| `RUN` | 构建时执行命令 | `RUN npm ci` |
| `CMD` | 启动默认命令（可被覆盖） | `CMD ["node","server.js"]` |
| `ENTRYPOINT` | 固定入口（不可被覆盖） | `ENTRYPOINT ["node"]` |
| `ENV` | 环境变量（运行期有效） | `ENV NODE_ENV=production` |
| `ARG` | 构建参数（仅构建期） | `ARG VERSION=1.0` |
| `EXPOSE` | 声明端口（仅文档，不映射！） | `EXPOSE 3000` |
| `VOLUME` | 声明匿名卷挂载点 | `VOLUME /data` |
| `USER` | 切换运行用户 | `USER node` |
| `HEALTHCHECK` | 健康检查 | `HEALTHCHECK CMD curl -f http://localhost/` |
| `LABEL` | 元数据标签 | `LABEL maintainer="me"` |
| `SHELL` | 改默认 shell | `SHELL ["/bin/bash","-c"]` |

## I. docker-compose.yml 字段速查

| 字段 | 作用 | 示例 |
|------|------|------|
| `services` | 顶层，定义所有服务 | `services:` |
| `image` | 用现成镜像 | `image: postgres:16` |
| `build` | 从 Dockerfile 构建 | `build: ./backend` |
| `ports` | 端口映射（建议加引号） | `- "8080:80"` |
| `environment` | 环境变量 | `- KEY=VALUE` 或 `KEY: VALUE` |
| `env_file` | 从文件读环境变量 | `env_file: .env` |
| `volumes` | 挂载（卷或绑定） | `- myvol:/data` |
| `depends_on` | 依赖（⚠️ 只管启动顺序） | `depends_on: [db]` |
| `condition` | 依赖条件（配合健康检查） | `condition: service_healthy` |
| `healthcheck` | 健康检查 | `test: ["CMD","curl","-f","http://localhost"]` |
| `restart` | 重启策略 | `restart: always` |
| `networks` | 指定网络（不写则默认共享） | `networks: [mynet]` |
| `command` | 覆盖镜像的启动命令 | `command: npm run dev` |
| `entrypoint` | 覆盖镜像的入口 | `entrypoint: ["node"]` |
| `container_name` | 指定容器名（默认自动生成） | `container_name: my-db` |
| `deploy.resources` | 资源限制 | `limits: { memory: 512M }` |
| 顶层 `volumes` | 声明数据卷 | `volumes: { myvol: }` |
| 顶层 `networks` | 声明网络 | `networks: { mynet: }` |

## J. 常见报错对照表

| 报错信息 | 原因 | 解决 |
|---------|------|------|
| `Cannot connect to the Docker daemon` | Docker Desktop 没启动 | 打开 Docker Desktop，等鲸鱼图标稳定 |
| `port is already allocated` | 端口被占用 | 换端口，或停掉占用的容器 `docker ps` 排查 |
| 容器 `Exited (0)` 秒退 | 主进程干完即结束 | 让容器跑一个常驻进程（如服务） |
| 容器 `Exited (137)` | 被 OOM 杀掉 | 提高 `--memory` 或修内存泄漏 |
| `exec format error` | 镜像架构不匹配（ARM↔x86） | 用 `buildx --platform` 构建多架构镜像 |
| `No such container` | 容器已退出/名字错 | `docker ps -a` 确认状态和名字 |
| `bash: not found` | 镜像没有 bash | 改用 `sh` |
| `Name or service not known` | 容器名解析不了 | 确认两容器在同一**自定义**网络 |
| 端口映射了但连不上 | 服务监听 127.0.0.1 | 让服务监听 `0.0.0.0` |
| 挂载后容器内文件不见 | 挂载点被宿主机目录覆盖 | 检查挂载路径，或用 `-v /app/node_modules` 保护 |
| `permission denied` 访问 Docker | 用户不在 docker 组 | `sudo usermod -aG docker $USER` 后重登 |
| 磁盘满 `no space left on device` | 镜像/容器/卷堆积 | `docker system df` 查，`docker system prune` 清 |
| build 很慢 | 构建上下文太大 | 加 `.dockerignore` 排除 node_modules/.git |
| 改了代码 build 没生效 | 用了缓存 | `docker build --no-cache`，或检查 `COPY` 顺序 |
| compose 改了 Dockerfile 没生效 | 没加 `--build` | `docker compose up -d --build` |
| backend 连不上 db | db 未就绪 / 网络不对 | 加 healthcheck + `condition: service_healthy` |

## K. 关键概念速记

| 概念 | 一句话 |
|------|--------|
| **镜像 Image** | 只读模板（菜谱），一个可起多个容器 |
| **容器 Container** | 镜像运行实例（做出来的菜），本质是"跑一个进程" |
| **Dockerfile** | 构建镜像的说明书（自动化装机流程） |
| **数据卷 Volume** | Docker 管理的持久存储（保险柜），存数据库数据 |
| **绑定挂载 Bind Mount** | 宿主机目录直连容器，开发热更新用 |
| **自定义网络** | 让容器能用**容器名**互相访问（默认网络不行） |
| **Compose** | 一个 YAML 描述整套服务，一条命令起停 |
| **`latest`** | 只是默认标签名，**不代表最新**，生产别用 |
| **`docker stop` vs `rm`** | stop 只是停（数据还在），rm 才是删 |
| **`depends_on`** | 只管启动顺序，**不保证服务就绪**（要配 healthcheck） |

## L. `docker run` 常用参数一览

```bash
docker run [OPTIONS] IMAGE [COMMAND] [ARG...]

-d              后台运行 (detach)
-it             交互式终端 (interactive + tty)
--rm            退出后自动删除容器
--name NAME     给容器命名
-p H:C          端口映射 宿主机:容器
-P              随机映射所有 EXPOSE 的端口
-e K=V          环境变量
--env-file F    从文件读环境变量
-v SRC:DST      挂载（卷名或宿主机路径 : 容器路径）[:ro]
--mount ...     显式挂载（type=volume|bind）
-w DIR          设置工作目录
--network NET   指定网络
--restart POLICY  重启策略 (no|on-failure|always|unless-stopped)
--entrypoint CMD  覆盖入口
--memory SIZE   内存限制
--cpus N        CPU 限制
--user UID      指定用户
--health-cmd     健康检查命令
```
